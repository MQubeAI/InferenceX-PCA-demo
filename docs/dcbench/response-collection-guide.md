# Response collection

1. Choose one context mode and fresh session. 2. Paste the standard prompt. 3.
Save complete raw response under `evaluation_responses/raw/`. 4. Enter the
answer in that model's template, retaining model/run/date/context metadata. 5.
Run the evaluator. 6. Save evaluator output under `evaluation_responses/scored/`.
Never give correctness feedback before a complete run.
